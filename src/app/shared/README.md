# Shared

Cartella per elementi Angular riutilizzabili tra feature diverse: pipe, directive, helper UI generici e modelli condivisi.

## Convenzioni future

- Mantenere il codice privo di dipendenze specifiche da una singola pagina.
- Preferire componenti standalone e API esplicite.
- Spostare nel FrameworkFrontend gli elementi che fanno parte del design system interno.
