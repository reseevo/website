# FrameworkFrontend

Design system e component library interna del website ReSeevo.

## Scopo

Questa area raccoglie gli elementi UI riutilizzabili secondo una logica Atomic Design: atoms, molecules, organisms, templates e pages.

## Convenzioni future

- Componenti standalone Angular.
- Nomi chiari, coerenti e orientati al ruolo del componente.
- Nessuna logica di dominio complessa nei componenti UI.
- Documentare varianti, stati e token quando il design system sara definito.
